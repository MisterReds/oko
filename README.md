# ОКО — мониторинг учебного класса

**ОКО Native 0.2.0** — настольное приложение для преподавателя и ученических ПК на Rust. Преподаватель просматривает экраны прямо в окне ОКО, **без браузера**.

## Установить на Linux x86-64

### Скачать готовую программу

**[GitHub Releases — скачать ОКО](https://github.com/MisterReds/oko/releases/latest)**

| Файл | Назначение |
|---|---|
| OkoTeacher-0.2.0-x86_64.AppImage | Полноценное окно преподавателя и сервер |
| OkoStudent-0.2.0-x86_64.AppImage | Окно ученика и агент |
| OkoNative-0.2.0-linux-x86_64.tar.gz | Portable-архив, без root |
| oko-native_0.2.0_amd64.deb | Debian / Ubuntu |
| OkoNativeSource-0.2.0.tar.gz | Исходники |

Для AppImage не требуются Rust, Docker или systemd:

~~~bash
chmod +x OkoTeacher-0.2.0-x86_64.AppImage
./OkoTeacher-0.2.0-x86_64.AppImage
~~~

На Calculate Linux и других системах без FUSE2:

~~~bash
./OkoTeacher-0.2.0-x86_64.AppImage --appimage-extract-and-run
~~~

Ученический AppImage запускается аналогично.

### Установить напрямую из GitHub

~~~bash
git clone https://github.com/MisterReds/oko.git
cd oko
bash scripts/install.sh both
~~~

Скрипт скачает файлы из **последнего опубликованного GitHub Release**, проверит SHA-256 и установит обе программы в домашний каталог. Создаст ярлыки в меню приложений, без sudo. Вместо both можно указать teacher или student.

**Важно:** этот способ требует, чтобы Release уже был опубликован. Для неопубликованных веток используйте сборку из исходников ниже.

## Как работает

1. **Преподаватель** запускает Teacher, получает нативное окно, видит экраны, выбирает ПК и отправляет команды. При первом запуске генерируются два разных ключа.
2. Для компьютеров в локальной сети преподаватель включает «Разрешить подключения из LAN» и передаёт ученикам только **ключ ученика** (не административный).
3. **Ученик** запускает Student, указывает адрес вида ws://192.168.1.10:7600, ключ и имя ПК, нажимает «Подключиться». Автозапуск выбирается отдельно.

### Совместимость

| Окружение | Статус |
|---|---|
| Linux x86-64 + X11 | Работает, тестировалось через Xvfb |
| Debian 12 / Ubuntu | Чистая установка проверена |
| Calculate Linux / Gentoo с X11 | Предназначено для использования; на реальном ПК ещё не проверено |
| wlroots Wayland с grim | Экспериментальный захват |
| GNOME/KDE Wayland | ScreenCast Portal ещё не реализован |
| ARM64, Windows, macOS | Готовые установщики пока не выпускаются |

GUI собран для x86-64 с glibc **2.35+** и системными библиотеками OpenGL/Mesa. На старых системах может потребоваться самостоятельная сборка.

**Безопасность:** протокол ws:// и HTTP в этой версии без TLS. Используйте доверенную учебную LAN либо VPN; не публикуйте порт 7600 напрямую в интернет. Ученический ключ не даёт административных прав. Блокировка X11 пока визуальная: клавиатура и мышь не блокируются.

## Сборка с GitHub

Потребуются Rust 1.91.1+, Cargo, pkg-config, компилятор C, development-пакеты X11/Wayland/OpenGL и системный пакет шрифта DejaVu Sans.

~~~bash
git clone https://github.com/MisterReds/oko.git
cd oko
bash scripts/build-local.sh
~~~

Готовые исполняемые файлы находятся в target/release (agent/master) и desktop/target/release (окно). Шрифт DejaVu используется при сборке из системной установки; отдельный файл шрифта в GitHub не публикуется.

## CI/CD

[GitHub Actions: Linux CI and Release](.github/workflows/linux.yml)

- Каждый push в main и Pull Request запускает встроенные Rust-тесты, проверку прав пользователей и запуск обоих GUI на виртуальном X11.
- Создаются AppImage, DEB, portable-архив и исходники, проверяются контрольные суммы.
- Сборки доступны в **Actions → Artifacts**.
- При создании тега v0.2.0 выполняется повторная сборка и, **после успешных проверок**, публикация файлов в GitHub Releases.

Нативные окна — в desktop/. Исходные Rust-сервер и агент — в src/. Старая веб-консоль оставлена в ui/ для совместимости, настольная программа её не открывает.
