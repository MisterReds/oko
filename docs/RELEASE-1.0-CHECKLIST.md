## Приоритет работ

1. **P0 — безопасность:** индивидуальные токены и отзыв каждого ученического устройства; постепенный отказ от токенов в URL.
2. **P0 — платформы:** полноценный XDG ScreenCast Portal/PipeWire для GNOME/KDE Wayland; тесты реального Calculate Linux.
3. **P1 — надёжность:** длительные испытания с 30 физическими ПК, перезагрузки, отказы сети, повторное подключение и корректная остановка агента.
4. **P1 — выпуск:** подписи релизов, SBOM, привязка внешних инструментов сборки к проверенным версиям, матрица Debian/Arch/Calculate.
5. **P1 — UX:** проверка возможности подключить весь класс, диагностировать неисправность и откатить обновление без терминала.

## Разрешение на выпуск 1.0.0

Версия 1.0 не должна объявляться стабильной, пока не закрыты все пункты P0 для заявленных систем и не завершён физический пилот на Calculate Linux (если этот дистрибутив заявляется поддерживаемым). После этого провести финальный CI на релизном теге, скачать готовые файлы с GitHub, проверить SHA-256, подписи и установку из инструкции.

**Ограничение:** текущие тесты подтверждают преимущественно виртуальный X11 и WSS. Они не доказывают поддержку всех Linux или GNOME/KDE Wayland.

## Диагностика и установка

- `bash scripts/doctor.sh` — быстрый отчёт о libc, архитектуре, сеансе и зависимостях (не включает захват).
- `bash scripts/install.sh both` — установка / обновление из GitHub.
- `bash scripts/rollback.sh both` — откат.
- `bash scripts/uninstall.sh both` — удаление с сохранением конфигурации.
